# Nickson Kaigi: Portfolio

Personal portfolio site of Nickson Kaigi, a full-stack Python engineer based in Nairobi, Kenya.

**Live site: [nickaigi.github.io](https://nickaigi.github.io)**

## About

Over a decade of experience building SaaS backends with Django, FastAPI and PostgreSQL, working remotely with teams in the UK, US and New Zealand. The site covers my impact, work experience, skills and education.

## Features

- Single-page layout with sections for impact, experience, skills and contact
- Light and dark themes, with a sun/moon toggle that remembers your choice
- Follows your device's theme setting by default
- Responsive, works on phones, tablets and desktops
- Accessible: keyboard focus styles and reduced-motion support
- No build step, no frameworks: one `index.html` file

## Run it locally

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/nickaigi/nickaigi.github.io.git
cd nickaigi.github.io
open index.html   # macOS; use xdg-open on Linux, or start on Windows
```

Or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

The site is hosted with [GitHub Pages](https://pages.github.com/). Pushing to the default branch of this repository publishes the changes automatically.
